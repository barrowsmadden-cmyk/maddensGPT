# Create HD

256x LabPBR textures for Create 6.0.10 on Minecraft 1.21.1 (NeoForge), built for the
Create+ based modpack. The textures are generated by the scripts in `tools/`.

## Status: samples

| Texture | Connects | Files |
|---|---|---|
| Andesite / Brass / Copper Casing | Create's own connected textures | `<name>.png`, `<name>_connected.png` (8×8 sheet, 2048 px), each with `_n` + `_s` |
| Industrial Iron Block (side + top) | Continuity (OptiFine CTM, `method=ctm`) | `optifine/ctm/industrial_iron_block[_top]/0-46.png` + `_n` + `_s` and a `.properties` |
| Brass Block | no | `brass_block.png` + `_n` + `_s` |
| Shaft | no | `axis.png`, `axis_top.png` + `_n` + `_s` |

## In-game setup

1. **Shader settings** (Rethinking Voxels / Complementary): *RP Support* (`RP_MODE`) must be
   **labPBR (RP Required)**. The default, *Integrated PBR+*, ignores resource-pack `_n`/`_s`
   maps. *POM Depth* scales the parallax depth.
2. **Resource pack order:** put this pack **above** AVPBR Retextured and CreatePlus Depth Addon,
   or their maps for the same blocks win.
3. **Continuity** must be enabled for the Industrial Iron Block to connect. The casings
   connect through Create itself and do not need Continuity.

## How the files map to the game

- Casings use Create's `OMNIDIRECTIONAL` connected type (`AllSpriteShifts`), an 8×8 sheet read
  row-major. `tools/ct.py` ports Create 6.0.10's `getTextureIndex` and generates each of the
  47 tiles from its connection context, so frames, planks and grain line up across blocks.
- Continuity tiles follow Continuity's `CtmSpriteProvider.SPRITE_INDEX_MAP` (copied verbatim in
  `tools/ct.py`). Continuity redirects Iris's `_n`/`_s` lookups to files next to each tile, so
  `0_n.png`/`0_s.png` beside `0.png` is all LabPBR needs.
- LabPBR 1.3: `_n` = DirectX normal (RG), AO (B), height (A, min 1); `_s` = smoothness (R),
  F0 or metal id (G: 230 iron, 234 copper, 255 albedo metal), porosity (B, ≤ 64), emission
  (A = 255, none). Complementary-based shaders do not read the `_n` AO channel, so the colour
  maps also carry a light baked AO.

## Building

```
cd tools
python3 build_pack.py ../build      # -> build/pack/ and build/CreateHD.zip
python3 preview.py <texdir> sheet.png
python3 ct_preview.py <texdir> walls.png
```

Requires Python 3 with numpy and Pillow.
